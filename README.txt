PAKET WEBSITE KUA KECAMATAN NGARIBOYO
====================================

Isi:
- index.html      : website utama
- style.css       : tampilan/responsive
- script.js       : menu mobile + kalender demo
- assets/logo-kemenag.jpg : logo yang diberikan
- assets/gedung-kua.svg    : gambar sementara; ganti dengan foto gedung KUA

PENTING UNTUK GOOGLE SITES:
Google Sites tidak mengimpor satu paket HTML sebagai situs secara langsung.
Gunakan desain/teks ini sebagai blueprint, lalu:
1. Buat Google Site baru.
2. Buat halaman: Beranda, Pendaftaran Nikah, Kalender Nikah, Layanan, Informasi, Galeri, Kontak.
3. Upload logo.
4. Embed Google Form resmi pada halaman Pendaftaran Nikah.
5. Embed Google Calendar resmi pada halaman Kalender Nikah.
6. Ganti nomor telepon, email, alamat, jam pelayanan, dan tautan resmi.
7. Publikasikan situs dengan domain/URL Google Sites.

Keamanan:
Jangan tampilkan NIK, dokumen KTP/KK, nomor pribadi, atau data sensitif calon pengantin pada halaman publik.
